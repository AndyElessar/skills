# Incremental Generator Template

Use this as a starting point for attribute-driven generators that emit one file per target. Rename placeholders and extract a repository-specific model before adding features. Requires `Microsoft.CodeAnalysis.CSharp` 4.14+ for `AddEmbeddedAttributeDefinition()`; see "Adaptation Notes" for older baselines.

```csharp
using System;
using System.Text;
using System.Threading;
using Microsoft.CodeAnalysis;
using Microsoft.CodeAnalysis.Text;

namespace MyGeneratorPackage;

[Generator]
public sealed class MyGenerator : IIncrementalGenerator
{
    private const string AttributeMetadataName = "MyGeneratorPackage.MyAttribute";

    public void Initialize(IncrementalGeneratorInitializationContext context)
    {
        context.RegisterPostInitializationOutput(static context =>
        {
            context.AddEmbeddedAttributeDefinition();
            context.AddSource("MyAttribute.g.cs", SourceText.From(AttributeSource, Encoding.UTF8));
        });

        IncrementalValuesProvider<MyModel> models = context.SyntaxProvider
            .ForAttributeWithMetadataName(
                AttributeMetadataName,
                // AttributeUsage already restricts targets, so the predicate can stay trivial.
                predicate: static (_, _) => true,
                transform: static (context, cancellationToken) => CreateModel(context, cancellationToken))
            .Where(static model => model is not null)
            .Select(static (model, _) => model!.Value)
            .WithTrackingName("MyGenerator.Models");

        // One output per model: an edit to one target only regenerates that target's file.
        context.RegisterSourceOutput(models, static (context, model) => Emit(context, model));
    }

    private static MyModel? CreateModel(GeneratorAttributeSyntaxContext context, CancellationToken cancellationToken)
    {
        cancellationToken.ThrowIfCancellationRequested();

        if (context.TargetSymbol is not INamedTypeSymbol typeSymbol)
        {
            return null;
        }

        string? ns = typeSymbol.ContainingNamespace.IsGlobalNamespace
            ? null
            : typeSymbol.ContainingNamespace.ToDisplayString();

        // Metadata name keeps generic arity (`Foo`1`) and avoids '<', ',' and spaces in hint names.
        string hintName = $"{ns}.{typeSymbol.MetadataName}".TrimStart('.').Replace('`', '_');

        return new MyModel(ns, typeSymbol.Name, hintName);
    }

    private static void Emit(SourceProductionContext context, MyModel model)
    {
        string namespaceLine = model.Namespace is null ? string.Empty : $"namespace {model.Namespace};";

        string source = $$"""
            // <auto-generated/>
            #nullable enable

            {{namespaceLine}}

            partial class {{model.TypeName}}
            {
                public const string GeneratedBy = "MyGenerator";
            }
            """;

        context.AddSource($"{model.HintName}.g.cs", SourceText.From(source, Encoding.UTF8));
    }

    private const string AttributeSource = """
        // <auto-generated/>
        #nullable enable

        namespace MyGeneratorPackage;

        [global::Microsoft.CodeAnalysis.EmbeddedAttribute]
        [global::System.AttributeUsage(global::System.AttributeTargets.Class, AllowMultiple = false, Inherited = false)]
        [global::System.Diagnostics.Conditional("MY_GENERATOR_USAGES")]
        internal sealed class MyAttribute : global::System.Attribute
        {
        }
        """;

    private readonly record struct MyModel(string? Namespace, string TypeName, string HintName);
}
```

## Adaptation Notes

- **Older Roslyn baseline (< 4.14):** remove `AddEmbeddedAttributeDefinition()` and `[EmbeddedAttribute]`, and ship the marker attribute in a companion assembly instead (see `references/project-packaging.md`). `ForAttributeWithMetadataName` itself needs 4.4+ (.NET 7 SDK).
- **Nested or generic targets:** this skeleton only handles top-level, non-generic classes. Emit the full containing-type chain and type parameters for nested or generic targets (see `generated-code-template.md`).
- **Aggregate outputs:** use `.Collect()` only when a single file must list every target (for example a registry). Sort the collected array by a stable key before emitting, and keep per-target files on separate per-item outputs.
- **Attribute arguments:** read `context.Attributes` (not `GetAttributes()`), handle both `ConstructorArguments` and `NamedArguments`, and bail out when any `TypedConstant.Kind` is `TypedConstantKind.Error`.
- Replace `MyModel` with a small equatable model. Do not pass `SyntaxNode`, `ISymbol`, `SemanticModel`, `Compilation`, or `Location` downstream.
- Prefer a separate analyzer for diagnostics. If the generator must report them, see `references/pipeline-design.md`.
- Add `WithTrackingName` to every stage that cacheability tests should inspect.
- `[Conditional]` on the marker removes the attribute from compiled metadata, so consumers carry no runtime dependency on it.
